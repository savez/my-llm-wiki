# raw/

**Ground truth immutabile.** Popolata da meccanismi automatici (skill di fetching da `inbox.md`, futuri RSS).

- `papers/` — PDF (paper, white paper, report)
- `web/<slug>/` — articoli web convertiti in markdown

**L'agente legge ma non scrive qui**, salvo via skill di ingestione automatica. Una volta dentro, immutabile. Mantieni la **lingua originale**: mai tradurre.

L'unica eccezione alla regola del "non scrivere" è l'operazione `FORGET`, che cancella su richiesta esplicita dell'utente.
