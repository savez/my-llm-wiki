# notes/

**Le tue note grezze, scritte a mano.** Destrutturate per design. Nessun frontmatter richiesto. Scrivi come ti viene.

Sottocartelle suggerite (puoi aggiungere/rinominare a piacere — l'agente scansiona ricorsivamente):

- `meetings/` — call, riunioni
- `conferences/` — appunti da talk, podcast, video
- `books/` — appunti di lettura
- `ideas/` — idee di progetto, brainstorm
- `scratch/` — zibaldone, pensiero libero

**L'agente le legge, le ingerisce, ma non le riscrive né impone struttura.** Sono tuo dominio.

La freschezza è tracciata via hash del contenuto, salvato in `last_synced_hash` nella source page corrispondente. L'operazione `SYNC` riconcilia.
